# Dashboard guide (Power BI Desktop, connected to the data warehouse)

The dashboard must read **the DW**, not CSV files. The BI-facing views already exist in schema `dw`
(created by `sql/dw_schema.sql` on the first load).

## 1. Connect
1. Start the stack (`docker compose up -d`) and run the DAG successfully at least once.
2. Power BI Desktop -> **Get data** -> **PostgreSQL database**.
3. Server `localhost:5433`, Database `music_dw`, mode **Import** (or DirectQuery). Credentials -> *Database*: user `etl_user`, password `etl_password`.
4. If Power BI asks for the **Npgsql** provider, install it from the link it shows and restart Power BI.
5. Select these views: `v_kpi_headline`, `v_kpi_popularity_by_decade`, `v_kpi_audio_by_decade`, `v_kpi_genre_summary`,
   `v_kpi_family_summary`, `v_kpi_match_coverage`, and optionally `v_nomination_detail` (row-level, for slicers/drill-through).

## 3. How to read it (put this in a text box on the report)
* Grammy-recognised tracks that exist in Spotify average **~60** popularity versus **~33** for the typical track of the same genres (lift **~+27**).
  The lift grows from about **+10 (1960s)** to **+33 (2010s)**.
* Audio profile: acousticness falls from ~0.60 (1950s) to ~0.22 (2000s); energy rises from ~0.45 (1960s) to ~0.65 (2000s); valence declines from ~0.74 to ~0.49; loudness rises from about -10 dB to -6.6 dB.
* Genres with most recognised matches: country, disco, blues, british, dance.

## 4. Mandatory caveats (data-product honesty)
* Only **6.3%** of Grammy records are matched (albums, people and records without artist are not matchable). Conclusions describe the *matched* subset.
* **n is small** in early decades (5 in the 1950s, 20 in the 1960s): do not over-interpret them (the 1950s bar is below baseline with n = 5).
* Spotify popularity is the **current** score, not popularity at award time.
* Grammy `winner` is unreliable, so "recognised" means winner **or** nominee (2019 lists all nominees, earlier years winners only).
* Multi-version tracks use the highest-popularity copy, which can bias popularity upwards.
